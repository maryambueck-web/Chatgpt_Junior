# Product Pitch

## Name

SafeChatGPT

## One-sentence pitch

SafeChatGPT is a protected web app that lets children use ChatGPT under parent-controlled, age-appropriate safety restrictions when the official ChatGPT webpage is blocked.

## Customer

Parents, schools, tutoring centers, and child-focused learning platforms that want the educational benefits of ChatGPT without giving minors unrestricted access.

## Why now

Children already want to use AI for homework and curiosity. Website blocking alone is too blunt: it blocks both risky and helpful use. SafeChatGPT offers a controlled middle path.

## Differentiation

- Uses ChatGPT as the underlying model.
- Assumes official ChatGPT access is blocked for the child.
- Provides a protected replacement interface.
- Checks both input and output.
- Detects attempts to disable parental mode.
- Can explain sensitive topics in safer educational language instead of only blocking.

## Future business model

- Parent subscription.
- School-managed classroom licenses.
- White-label API for child-safe learning apps.
